    SASA converts digital full scale to pascals using a single factor, Pa/FS. Every level it reports — peak, exposure, band and hazard — depends on that one number. It is recorded in the analysis metadata alongside the method used to obtain it.

    Shot detection

    How individual shots are found in the recording

    Sensitivity
    shots

    Optional. If a threshold produces this count it is preferred; if none does, the run says so rather than forcing it.

    dB

    How far above the noise floor a candidate must be to count as a shot. Candidates below it are rejected, not flagged — real muzzle blast clears its noise floor by 30–60 dB. Applies in both modes, and raising it narrows the range the tuner searches. Range 0–80 dB.

    Threshold mode
    dB below peak

    Range 1–90 dB below peak. Typical 15–25.

    ms

    Minimum gap between shots. Range 10–5 000 ms.

    ms

    Captured before the arrival. Range 1–500 ms.

    ms

    Must outlast the decay or B-duration will be truncated. Range 50–5 000 ms.

        Suppressor behaviour First-round pop

        Not measured

        The first round through a suppressor that has been sitting burns the air trapped inside it and is louder than those that follow. One first round against a string is a single observation, so SASA tests it against the interval a further shot would have been expected to land in, and reports the result either way.
